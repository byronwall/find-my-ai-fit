# AI Use Case Grid — Visual System

## Direction

The product is a strategy-studio workspace: precise enough for serious work, vivid enough to make exploration feel energizing. It rejects the cream-and-serif AI-tool default in favor of a cool paper field, near-black structural ink, electric periwinkle, and a sharp citrus signal.

## Color

- `canvas` is a cool, lightly blue working surface; `panel` is clean white.
- `ink` provides structure and the dark application header.
- `green` is the electric periwinkle action color. The token name is retained for compatibility.
- `signal` is citrus and is reserved for selected, recommended, or high-attention moments.
- Teal and amber are categorical fills, not decorative confetti.
- Borders are visible and cool-toned. They define a grid; they do not imitate soft cards.

## Typography

- Use the native humanist sans stack: Avenir Next, Segoe UI Variable, and system sans fallbacks.
- Display copy is heavy, compact, and slightly tightened; it is never set in a decorative serif.
- Body copy stays between 65–75 characters when it is meant to be read.
- Small labels use weight and concise language more often than uppercase tracking.

## Shape and depth

- Prefer crisp 4–10px radii, asymmetric corners, and occasional square edges.
- Primary surfaces can use an offset hard shadow plus a restrained soft shadow.
- Cards are content regions inside the matrix, not floating tiles. Avoid cards inside cards.

## Interaction hierarchy

- Every screen has one visually dominant next action.
- Save, dismiss, restore, and start-over controls are progressively disclosed in contextual menus.
- The personalized upload and build action lead the landing page; the complete HR example is a fallback.
- Desktop workspaces permanently reserve the inspector rail so opening and closing an idea never resizes the matrix.
- Selection is persistent and high-contrast; hover is only a preview.
- Motion is short and purposeful. Respect reduced-motion preferences.

## Responsive behavior

- The landing page pairs a concise promise with the profile intake, then demonstrates the real 3×3 mechanism as the next full-width beat.
- The desktop matrix reads as a strategy board.
- Mobile becomes one work level at a time with explicit value tabs.
- Controls remain at least 40px high where space permits and never depend on hover alone.
